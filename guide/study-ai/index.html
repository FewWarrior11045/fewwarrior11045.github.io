공부용 AI 추천, 결제는 해야 할까?

AI 도감 · 2026-10-12

공부할 때 AI를 쓰려고 하면 제일 먼저 드는 고민이 "뭘 써야 하지?"랑 "돈 내야 하나?"예요. 결론부터 말하면, 처음엔 무료로 충분하고, 부족할 때 하나만 결제하면 돼요.

모르는 개념 질문 · 오답 풀이

ChatGPT, Gemini, Claude 중에 아무거나 하나면 무료로도 기본 사용이 돼요. 문제를 사진으로 찍어 올리면 풀이를 해 주고, 이해가 안 되는 부분을 계속 물어볼 수 있어요. 셋 다 써 보고 설명 방식이 나한테 잘 맞는 걸 고르는 게 제일 좋아요.

수학 문제 풀이

수학 문제는 콴다가 편해요. 문제 사진만 찍으면 풀이를 바로 찾아 줘서, 챗봇한테 문제를 하나하나 설명하는 것보다 빨라요.

시험 범위 공부

NotebookLM은 교재나 강의 자료 PDF를 넣으면 그 자료 안에서 답해 줘요. 시험 범위 밖 엉뚱한 내용을 섞을 일이 줄어서, 내 자료로 요약하고 문제를 만들어 보기 좋아요.

결제는 언제 할까?

  • 질문을 많이 해서 무료 사용량이 자꾸 막힐 때
  • 긴 PDF나 사진 여러 장을 한 번에 분석시키고 싶을 때

이럴 때 하나만 결제하면 돼요. 공부용으로 ChatGPT와 Gemini를 둘 다 결제할 필요는 거의 없어요. 학생 할인이나 무료 체험이 있을 때도 있으니 결제 전에 공식 사이트를 한 번 확인해 보세요.

공부가 되는 질문법

  • "답 알려줘" 대신 "내가 어디서 틀렸는지 단계별로 설명해 줘"라고 물어보기
  • 이해가 안 되면 "더 쉽게, 예시를 들어서 다시 설명해 줘"
  • AI도 계산이나 사실을 틀릴 때가 있어요. 시험에 나올 내용은 교재와 꼭 비교하기

가격, 무료 사용량, 기능은 자주 바뀌어요. 쓰기 전에 각 서비스의 공식 사이트에서 확인해 주세요.
